# SpecKit 环信IM WebDemo 自动化测试需求规范 SDD
## 业务系统：环信 Easemob 即时通讯 Web 聊天室 Demo
## 技术栈：Playwright + Pytest + PO模式 + Allure
## 核心页面：页面1（聊天室列表页）、页面2（聊天室内页）

## 0. 测试数据构建规范（新增，强制）
### 0.1 原则
- 聊天室自动化用例所需的用户、聊天室，不依赖手工预置数据
- 优先通过服务端 API 在用例执行前动态创建测试数据
- 每次执行使用唯一数据，避免环境污染、数据争抢、状态串用
- 测试数据需支持清理；若场景失败，至少保留创建日志与资源标识，便于手工回收

### 0.2 数据创建顺序
1. 先创建测试用户
2. 再创建聊天室
3. 将创建出的 owner、members、roomId 回填到 UI 自动化上下文
4. UI 用例基于新建数据执行加入、进入、消息发送、成员管理、公告、属性等场景

### 0.3 必须支持的服务端数据能力
- 创建用户：`UsersApi.create_user`
- 删除用户：`UsersApi.delete_user`
- 创建聊天室：`ChatroomManagerApi.create_chatroom`
- 配置读取：从配置文件读取 `base_url`、`org_name`、`app_name`、`grant_type`、`client_id`、`client_secret`、`ttl`

### 0.5 当前约定 API 能力

- 用户删除接口：`UsersApi.delete_user(username)`
- 聊天室创建接口：`ChatroomManagerApi.create_chatroom(name, description, owner, members=None, maxusers=1000, custom=None, roomid=None)`

### 0.6 测试数据命名要求
- 用户名、昵称、聊天室名称、聊天室 roomid 必须带唯一后缀
- `roomid` 仅使用小写字母和数字
- 聊天室名称、描述需体现来源，例如 `playwright`、`chatroom-auto`、时间戳

### 0.7 数据断言闭环
- 服务端创建成功后，需断言返回体包含有效用户标识或聊天室标识
- UI 登录后，需断言创建出的用户可以成功登录
- UI 聊天室列表中，需断言新创建聊天室可见
- 若聊天室 owner / members 为预置关系，需断言列表按钮状态符合预期：
  - owner / member 已在房间中：显示 `进入`
  - 非成员：显示 `加入`

## 一、场景分层定义（严格区分 client/server/console/callback）
1.  **Client 客户端UI场景**
用户页面操作、消息收发、房间浏览、按钮交互、界面展示校验
2.  **Server 服务端逻辑场景**
房间权限变更、成员关系、禁言状态、黑白名单、转让解散后台生效
3.  **Console 管理后台场景**
聊天室全局配置、公告管理、房间属性配置、批量权限管控
4.  **Callback 回调事件场景**
成员进出、状态变更、禁言解禁、解散转让、属性修改事件回调UI同步校验

## 二、全量测试用例范围
### 1. 聊天室基础流程
- 页面登录校验
- 服务端创建测试用户与聊天室
- 聊天室列表刷新、搜索筛选
- 加入聊天室、进入已有聊天室、查看房间详情
- 房间成员数量UI展示断言
- 页面1（聊天室列表页）与页面2（聊天室内页）切换校验

### 2. 消息收发全类型（支持页面1→页面2联动，双页面校验）
#### 2.1 页面关联说明
- 页面1（聊天室列表页）：触发进入指定聊天室，跳转至页面2；可查看未读消息提示、消息预览
- 页面2（聊天室内页）：核心消息收发操作页，展示完整消息列表、消息发送控件、消息状态

#### 2.2 全类型消息收发用例（双页面联动校验）
1.  文本消息
    - 页面2：输入文本消息，点击发送按钮
    - 校验：页面2消息列表回显文本、发送状态（已发送/已读）、发送时间
    - 联动校验：页面1对应聊天室显示未读消息数（未读场景）、消息预览内容
2.  图片消息
    - 页面2：点击图片上传按钮，选择本地图片发送
    - 校验：页面2图片消息正常显示、可预览、发送状态正常
    - 联动校验：页面1对应聊天室显示图片消息预览标识、未读提示
3.  文件消息
    - 页面2：点击文件上传按钮，选择本地文件（文档、压缩包等）发送
    - 校验：页面2文件消息显示文件名、文件大小、可下载，发送状态正常
    - 联动校验：页面1对应聊天室显示文件消息提示、未读计数
4.  语音消息
    - 页面2：点击语音录制按钮，录制语音后发送
    - 校验：页面2语音消息显示时长、可播放，发送状态正常
    - 联动校验：页面1对应聊天室显示语音消息标识、未读提示
5.  视频消息
    - 页面2：点击视频上传按钮，选择本地视频发送
    - 校验：页面2视频消息可播放、显示时长、发送状态正常
    - 联动校验：页面1对应聊天室显示视频消息标识、未读计数
6.  自定义消息
    - 页面2：选择自定义消息类型，配置消息内容后发送
    - 校验：页面2自定义消息按预设格式显示、发送状态正常
    - 联动校验：页面1对应聊天室显示自定义消息预览、未读提示
7.  透传消息
    - 页面2：发送透传消息（不显示在普通消息列表，仅触发回调）
    - 校验：页面2无冗余显示，透传事件回调正常
    - 联动校验：页面1无多余消息提示，回调日志正常
8.  位置消息
    - 页面2：选择位置，发送当前位置消息
    - 校验：页面2位置消息显示坐标/地图预览、发送状态正常
    - 联动校验：页面1对应聊天室显示位置消息标识、未读提示

#### 2.3 消息收发异常场景（双页面校验）
- 无权限发送消息（被禁言）：页面2发送按钮置灰/不可点击，提示禁言信息；页面1无消息预览
- 网络异常发送消息：页面2提示发送失败，可重试；页面1无对应消息提示
- 发送超大文件/图片：页面2提示超出限制，发送失败；页面1无相关预览
- 接收消息：页面2实时接收消息、自动刷新；页面1同步更新未读计数、消息预览

### 3. 聊天室成员权限管控
- 用户主动加入、主动退出聊天室
- 管理员移除成员
- 指定成员禁言、解除成员禁言
- 一键全局禁言
- 设置房间管理员、移除管理员权限
- 成员黑名单添加/移除
- 成员白名单添加/移除

### 4. 房间配置管理
- 新增聊天室公告
- 更新修改聊天室公告
- 删除聊天室公告
- 设置聊天室自定义属性
- 删除聊天室自定义属性

### 5. 房间生命周期管理
- 聊天室所有权转让
- 聊天室解散操作与状态校验

### 6. 全事件监听回调校验
用户进出房间、权限变更、禁言状态、公告变更、属性变更、转让解散、消息收发
UI界面（页面1+页面2）状态与服务回调事件一致性双向断言

## 三、自动化验收标准
1.  所有用例无依赖、可独立重复执行
2.  测试用户与聊天室优先通过服务端 API 动态构建，不依赖人工环境数据
3.  UI操作（双页面联动）与服务接口结果双向校验闭环
4.  页面元素变更自动适配，不出现偶发失败
5.  覆盖Excel表格全部聊天室监听事件及双页面消息收发场景
6.  输出标准化测试报告，支持CI流水线定时回归
7.  异常场景、边界场景全覆盖
8.  双页面切换流畅，消息状态同步一致，无延迟、无错乱
